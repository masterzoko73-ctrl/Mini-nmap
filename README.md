# mini-nmap

Lightweight TCP port scanner written in Python with multithreading and basic service detection.

## Что это

`mini-nmap` — небольшой консольный TCP-сканер портов на Python. Он проверяет доступность портов на указанном хосте и пытается определить сервис по стандартному имени порта и полученному баннеру.

## Что умеет

- сканировать порты 1–1024 по умолчанию;
- проверять один порт в формате `host:port`;
- использовать до 10 рабочих потоков;
- определять сервисы по баннерам (например, HTTP, SSH, FTP, SMTP, MySQL и Redis);
- принимать доменное имя или IPv4-адрес;
- выводить открытые порты, их состояние и предполагаемый сервис.

## Как запустить

Требуется Python 3. Запуск не требует установки зависимостей: используются только стандартные библиотеки Python.

```bash
python main.py
```

После запуска введите доменное имя или IPv4-адрес:

```text
Target: scanme.nmap.org
```

Для проверки одного порта используйте:

```text
Target: 127.0.0.1:22
```

## Пример вывода

```text
Target: 127.0.0.1:22
Host: 127.0.0.1
Port: 22
PORT       STATE      SERVICE
22/tcp open ssh
```

Результат зависит от доступности хоста, настроек firewall и работающих сервисов.

## Ограничения

- сканируются только TCP-порты;
- по умолчанию проверяется диапазон только 1–1024;
- IPv6 не поддерживается;
- одновременно используется не более 10 потоков;
- определение сервиса по баннеру эвристическое и может быть неточным;
- тайм-аут соединения и чтения баннера составляет 1 секунду;
- программа не определяет версии сервисов и не выполняет полноценное fingerprinting;
- сканируйте только системы, на которые у вас есть разрешение.

## Технологии

- Python
- `socket` — TCP-соединения, DNS-разрешение и чтение баннеров;
- `threading` — параллельная обработка портов;
- `queue` — очередь заданий для рабочих потоков.
